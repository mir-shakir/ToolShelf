What is Unix / epoch time?

Unix epoch time (also called Unix time, POSIX time, or simply epoch) is a system for describing a point in time as the number of seconds that have elapsed since 00:00:00 UTC on 1 January 1970, not counting leap seconds. It's the most widely used timestamp format in computing — from database timestamps and API responses to JWT iat/exp claims.

Seconds vs milliseconds vs microseconds vs nanoseconds

Epoch values appear in several precisions depending on the system:

UnitDigits (today)Typical source
Seconds (s)10Unix date +%s, most SQL EXTRACT(EPOCH FROM …)
Milliseconds (ms)13JavaScript Date.now(), Java System.currentTimeMillis()
Microseconds (μs)16Python time.time_ns() / 1000, Postgres clock_timestamp()
Nanoseconds (ns)19Go time.Now().UnixNano()

Heuristic: a modern timestamp of length 10 is almost certainly seconds; length 13 is milliseconds. This tool auto-detects on paste.

Timezones and epoch time

An epoch number is absolute — it represents a single instant in time, independent of timezone. Timezones matter only when rendering that instant as a human-readable date. Choose the timezone dropdown above to see how the same timestamp looks in UTC versus your local zone.

The Year 2038 problem

Systems that store Unix timestamps as 32-bit signed integers overflow on 19 January 2038 at 03:14:07 UTC. 64-bit storage (the default on modern platforms and in this tool) is unaffected. See our full guide for the details.

FAQ

What is Unix epoch time?

The number of seconds since 00:00:00 UTC on 1 January 1970, not counting leap seconds.

How do I convert milliseconds to seconds?

Divide by 1000 and floor. This tool does it automatically — just pick the ms unit.

Why does my timestamp show the wrong time?

Almost always a unit or timezone issue. 13 digits = milliseconds, 10 digits = seconds. Check the TZ dropdown.

What's the difference between ISO 8601 and RFC 3339?

RFC 3339 is a stricter internet-friendly subset of ISO 8601.

Does this tool work offline?

Yes — every conversion runs in your browser. Nothing is sent to a server.

What is the Year 2038 problem?

32-bit signed epoch storage overflows on 19 January 2038 at 03:14:07 UTC. This tool uses 64-bit math and is unaffected.

Can I use negative timestamps (before 1970)?

Yes. The tool handles negative epoch values.

How accurate is the relative time?

It uses Intl.RelativeTimeFormat and ticks every second. Accuracy is limited by your system clock.
